## Conventions

- **Source of truth:** GitHub Issues. This roadmap is the strategy/sequencing view, not a parallel tracker.
- **One PR per branch.** Multi-close via `Closes #N, #M, #O` in PR body.
- **Pre-plan docs (`docs/plans/<branch>-fix.md`)** for active CC handoffs only. Purge after the PR ships (issue history becomes the durable record).
- **Critical label** = hot recent bug OR cleanup-branch candidate (operator definition).
- **`needs-design` label** = operator alignment required before any code.
- **`batch-candidate` label** = small enough to bundle with another PR.
